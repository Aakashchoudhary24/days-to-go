name: days-to

core: web app to add/maintain/monitor several instances of timers which represent days-until some event or the days to
go for some event/deadline/aim/goal/task etc. 

minimum usecase/problem it arises from: I want to get on a fitness streak before I reach home for semester end and want
to surprise parents with a good phyique and also get in shape for a wedding, also prepare for jobs etc (i've set a 
personal deadline for it). All these tasks would be better if I could see how many days I have left for each.

design ideas:
1. minimal as fuck
2. on landing if there are no tasks set immediately give a task setup pipeline/walkthrough/box
3. task setup requires the name of the task, calendar to select the date, typa goal/option to add priority (high, medium
, low)
4. once the task is done the view appears in the middle with a timer running. Huge text stating "X days to go" and a 
timer running in the center of the screen
5. if there are more than one tasks set, a scroll menu on the left edge of the screen to choose from the tasks to put
on main central display, or even pin several tasks on the central display in which case each task gets shaped accordingly
6. if two tasks (square div) -> side by side (assuming the central display/stage is a rectangle)
7. if 3 tasks -> side by side -> adjust anyhow, shape doesn't matter
8. if 4 tasks -> grid display
9. allow only 4 tasks on the display at a time.
10. color pallete -> black, white for now, rest decide later.
